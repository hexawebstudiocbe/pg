# Premium PG Accommodation Website - Coimbatore

A visually extraordinary, highly interactive, and premium PG accommodation website built with HTML5, CSS3, Bootstrap 5, and Vanilla JS.

## Features

- **Premium Design:** Modern, clean, and elegant aesthetics prioritizing visual excellence.
- **Responsive:** Fully responsive across all devices (mobile to large desktop).
- **Interactive UI:** Smooth scroll effects, floating elements, micro-interactions with AOS.js and CSS.
- **Dynamic Components:** Swiper.js image galleries, JavaScript-based room filtering, animated counters.
- **SEO Ready:** Semantic HTML, Open Graph tags, JSON-LD Schema placeholder.
- **No Heavy Frameworks:** Pure frontend stack without React, Vue, or Tailwind for easy beginner/intermediate modification.

## How to Customize (Placeholders)

Throughout the HTML code, you will find placeholders in uppercase brackets `[LIKE THIS]`. 
Simply replace them with actual business information before deploying:

- `[PG BRAND NAME]`
- `[PHONE NUMBER]`
- `[WHATSAPP NUMBER]`
- `[EMAIL ADDRESS]`
- `[PG ADDRESS]`
- `[PRICE]`
- `[CANONICAL URL]`
- Policy placeholders (e.g., `[WIFI POLICY PLACEHOLDER]`)

## Setup

1. Open `index.html` in any modern web browser.
2. Edit files directly in any code editor (e.g., VS Code).
3. No build steps required.
